# Unoffical LineageOS ROM for Nubia Z11 Mini S

version: lineage 17.1 (android 10)

## Features
- F2FS support for data/cache  
- Project Treble enabled with VNDK Lite 29.0  

## What works:
- Calls/SMS/Mobile data  
- Wifi  
- Bluetooth  
- GPS  
- Camera (Photo/Video/Flashlight)  
- Audio  
- DT2W  
- Keydisabler  
- Notification LED  
- Torchlight
